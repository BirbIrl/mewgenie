MewGenie - a Mewgenics Encyclopedia by Birbirl

If you stumble upon any bugs or issues, please report them over on the issue tracker.

This project is made of two parts:

  • MewGenie-Unboxer - a data parser that automatically extracts and compiles the game's .gon, .csv and .swf files into json's and svg's.
  • MewGenie - the website used to display that data, you're seeing it now!
Both are licensed under GPL 3.0, which means you're free to make your own versions of this software if you follow the license.

The goal of this project is to set a baseline of quality for free tools for mewgenics that respect your time and privacy.
